<img src="h-about.svg" width="760" alt="about" />

<p>
  I build software end to end &mdash; the API, the data model, the interface, and
  the pipeline that ships it. Most of my work has been systems that someone
  actually has to use on a Monday morning: inventory and stock ledgers, clinic
  records, loan management, a queuing kiosk for a barangay office. That kind of
  work rewards being careful about the boring parts, which is where I like to be
  careful.
</p>

<p>
  I work across a wide stack because the problems have been wide &mdash; PHP and
  Java for records systems, C# for desktop tools, Python for anything with a
  model in it, TypeScript on the front end. I am most at home in the backend,
  and most interested in the seam where backend meets infrastructure: what makes
  a service predictable, observable, and cheap to operate once it is live.
</p>

<p>
  Alongside that I keep a security habit &mdash; secrets hygiene, dependency
  discipline, and reading a system for how it fails before assuming how it works.
</p>
